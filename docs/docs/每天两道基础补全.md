java基础{
   1. jvm：它是java一次编写到处运行的基础，jvm本质也是一个程序，它可以把我们编译后的.class运行，所以只要有jvm我们的源码就可以运行，但是我们的源码没有做任何的修改，注意哪怕项目打包要运行也是需要jvm的。
   2. JVM、JDK、JRE三者关系：JDK大于JRE大于JVM，jdk中包含Java的运行工具包和jvm，JRE是Java运行时环境，JRE不包含开发工具，只提供Java程序运行所需的运行环境。
   3. integer是引用类型，是对int类型的封装,就是把int类型包装成Object对象,原因：有些功能只能对对象使用，如果使用int类型的数据，一些功能可能不能正常使用，Java中集合中只能存储对象，常规的int数据无法存入所以使用intrger类型，优缺点，int是基本数据类型，是预定义的不需要实例化，没有额外的内存开销，integer是引用类型，使用时需要实例化，所以int在读写数度上都是integer的好几倍，且int类型默认只能为0，但是integer可以为null可以做一些空值的判断。
   4. 什么是面向对象：它将现实世界中的事物抽象为对象，对象具有属性（称为字段或属性）和行为（称为方法）。
   5. Java面向对象的三大特性包括：封装、继承、多态：1.封装：让对象只通过接口与外部交互，保证对象的安全和简化开发。 2. 继承：让子类可以使用父类的代码功能，是一张代码复用的手段。 3. 多态：让同一个接口可以实现不同的实现类执行不同的功能。
   6. 多态的体现：1. 方法的重载：虽然方法名字相同，但是根据传入的数据不同，执行不同的功能 2，重写：子类可以通过重写父类的方法，扩展不同的功能，并且jvm根据具体的类属性来判断，是执行父类还是子类。3.接口与实现：实现同一个接口可以有多个实现类，及时同一个接口，也可以实现不同的功能。4.接口与实现：多态：可以让子类继承父类，扩展父类的功能等提高了代码的复用性和扩展性。
   7. @override注解表示对父类的重写和对接口的实现
   8. 普通类和抽象类的区别：普通类可以单继承，要有具体的实现，可以实例化对象可以有方法。 抽象类：不能实例化对象，也可以有方法 。但是普通类可以直接new（开辟内存）普通类去实现对应的方法，抽象类中的方法和new只能被继承的子类去实现，去new，不能加final字段，因为它要被继承. 接口是一个规范，让所有实现它的方法按照对应的模板，并且接口不能创建对象实现方法，只能定义模板，具体方法要由实现类去实现，一个接口可以有多个实现类。
